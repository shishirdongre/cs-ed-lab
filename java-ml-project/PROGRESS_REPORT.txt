HOW THE FORM WAS CREATED:

Question Files:
- All questions stored as JSON files in: java-ml-project/questions/
- Each question file follows a structured JSON format with type, title, description, and question-specific fields
- Question types include: paragraph, short_answer, scale, checkbox, multiple_choice, and group (which expands into sub-questions)
- Files are numbered sequentially (000_student_id.json, 001_section_pre_survey.json, etc.) to maintain order
- Post-reveal questions created for each reveal section (094_post_reveal_0_1.json through 131_post_reveal_7_1e.json)

Form Creation Script:
- Script: java-ml-project/create_google_form.py
- Script reads all JSON files from questions/ directory in sorted order
- Expands question groups into individual form items
- Uses Google Forms API to create form and add questions
- Processes questions in batches of 20 to avoid API limits
- Handles OAuth authentication with provided credentials file
