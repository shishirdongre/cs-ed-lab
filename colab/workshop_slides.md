# How to Answer Reflection Questions

<div class="text-left">

## Answering Guide

When you see reflection prompts, structure your responses like this:

### Level 1: Basic Understanding
- Describe what you see in the code
- State what you think it does (even if you're unsure)
- Example: "This code is importing a function. I don't know what the function is for."

### Level 2: Detailed Understanding
- Explain the purpose of the code
- Describe which library/function is being used
- Explain what the function does
- Example: "This code is to import functions from the scikit-learn library. The function is used to split the dataset into train and test datasets."

### Remember
- **Both levels are valuable!** Answer at whatever level you're at
- Be honest about what you know and don't know
- Use specific examples when possible
