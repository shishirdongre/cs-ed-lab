# Workshop Description: Text Classification with Machine Learning

## Overview

This interactive workshop introduces students to **text classification** using machine learning techniques. Through hands-on practice with real-world datasets, participants will learn how to build and evaluate text classifiers that can automatically categorize text based on sentiment or formality.

## What You'll Learn

### Core Concepts
- **Text Preprocessing**: Cleaning and preparing text data for machine learning
- **Feature Extraction**: Converting text into numerical features using Bag-of-Words and TF-IDF
- **Model Training**: Building classifiers using Naive Bayes and Logistic Regression
- **Model Evaluation**: Understanding accuracy, precision, recall, and confusion matrices
- **Error Analysis**: Identifying and improving model weaknesses

### Hands-On Activities

1. **Yelp Sentiment Analysis Workshop**
   - Analyze restaurant reviews to classify them as positive or negative
   - Explore real-world text data and understand feature engineering
   - Practice data cleaning and normalization techniques
   - Build sentiment classifiers and evaluate their performance

2. **Formal vs. Slang Classifier**
   - Create your own dataset by labeling words and phrases as formal or slang
   - Train multiple classification models (Naive Bayes, Logistic Regression)
   - Compare different text vectorization methods (Bag-of-Words vs. TF-IDF)
   - Perform error analysis to improve model accuracy

## Workshop Structure

The workshop is designed as an interactive Google Colab notebook with:
- **Step-by-step guidance** through each machine learning concept
- **Reflection prompts** to deepen understanding
- **Interactive widgets** for data entry and model testing
- **Visualizations** including confusion matrices and performance metrics
- **Self-paced learning** with solution cells for reference

## Expected Outcomes

By the end of this workshop, you will be able to:
- Understand the fundamentals of text classification
- Preprocess and clean text data for machine learning
- Build and train simple text classifiers using scikit-learn
- Evaluate model performance using appropriate metrics
- Identify areas for model improvement through error analysis
- Apply these techniques to your own text classification problems

## Prerequisites

- Basic Python programming knowledge
- Familiarity with pandas DataFrames (helpful but not required)
- No prior machine learning experience necessary!

## Tools & Technologies

- **Python** with scikit-learn, pandas, numpy
- **Google Colab** for interactive notebook environment
- **Jupyter widgets** for interactive learning components
