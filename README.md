# CS Education Lab

This repository contains educational materials and projects for computer science education.

## 📁 Directory Structure

### `/colab/` - Collaborative Materials
Contains existing collaborative materials and notebooks:
- `java_notebook.ipynb` - Java programming notebook
- `python_notebook.ipynb` - Python programming notebook  
- `src/` - Source code from collaborative work
- `Copy of CS46A Slides/` - CS46A course slides

### `/java-ml-project/` - Java Machine Learning Project
Complete Java-based machine learning project for teaching text classification:

#### 🎯 **Main Features:**
- **Complete ML Pipeline**: Data loading, preprocessing, training, evaluation
- **Two ML Models**: Naive Bayes and Logistic Regression classifiers
- **BlueJ Compatible**: Simplified classes for teaching beginners
- **Professional Grade**: Full evaluation metrics and comprehensive features

#### 📚 **Teaching Materials:**
- **BlueJ Classes**: Ready-to-use classes for visual learning
- **Teaching Guide**: Step-by-step instructions for educators
- **Documentation**: Comprehensive README files
- **Sample Data**: Formal vs slang word classification dataset

#### 🚀 **Quick Start:**
1. **For BlueJ Teaching**: Use classes in root directory
2. **For Full Pipeline**: Run `mvn exec:java` or `./compile_and_run.sh`
3. **For Development**: Use Maven build system

#### 📖 **Documentation:**
- `README.md` - Main project documentation
- `TEACHING_README.md` - BlueJ teaching guide
- `IMPLEMENTATION_PLAN.md` - Development roadmap

## 🎓 **Educational Use**

This repository is designed for:
- **Computer Science Education**

- Java 11+
